1. UNDERSTAND THE PROJECT
   ==================================================

The purpose of this project is to create a web platform that helps buyers determine whether a product listed on Government e-Marketplace (GeM) is competitively priced.

The platform should compare a GeM product with equivalent products from other marketplaces such as Amazon Business, Flipkart and IndiaMART.

The system should:

1. Allow a user to search for a product.
2. Find the relevant GeM product.
3. Find equivalent products from other marketplaces.
4. Match products intelligently even when product names are slightly different.
5. Compare prices side-by-side.
6. Calculate the market average.
7. Identify whether the GeM price is above, below, or close to the market price.
8. Calculate potential savings.
9. Show price history.
10. Provide a buyer dashboard.
11. Highlight products that may require price review.
12. Provide a Refresh Prices feature.

The PPT proposes:

* Python
* BeautifulSoup / Selenium
* RapidFuzz
* FastAPI
* SQLite / MongoDB
* React or Streamlit

For this prototype, prefer:

Frontend:
React + Vite

Styling:
Tailwind CSS

Backend:
Python + FastAPI

Database:
SQLite

Product matching:
RapidFuzz

Charts:
Recharts

Initially use a PRE-CACHED DEMO DATASET instead of depending completely on live scraping.
